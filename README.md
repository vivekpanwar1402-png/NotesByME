# NotesByME

एक हल्का, तेज़ और सुंदर अध्ययन वेबसाइट — कक्षा 10 के हिंदी-माध्यम छात्र के लिए, उत्तराखंड बोर्ड (UBSE) सामाजिक विज्ञान की तैयारी के लिए।

**मुख्य लक्ष्य:** व्यवस्थित पढ़ाई, दोहराव, क्विज़ और प्रगति के ज़रिए 90+ अंक तक पहुँचना।
**इस बैच का मुख्य मॉड्यूल:** इतिहास → महत्वपूर्ण तिथियाँ।

---

## अभी क्या-क्या है (Current features)

- **PIN लॉक स्क्रीन** — साइट खुलने पर सबसे पहले 4 अंकों का एक्सेस गेट (मोबाइल कीपैड, बैकस्पेस, साफ़ करें, कीबोर्ड इनपुट, Enter सपोर्ट, ग़लत PIN पर साफ़ एरर और शेक एनिमेशन)। यह केवल एक सरल क्लाइंट-साइड गेट है — सुरक्षा व्यवस्था नहीं।
- **होम डैशबोर्ड** — स्वागत, मुख्य फ़ीचर (इतिहास तिथियाँ), क्विज़, रिवीज़न, प्रगति और आने वाले मॉड्यूल की झलक।
- **इतिहास — महत्वपूर्ण तिथियाँ** — सत्यापित 41 तिथियाँ (अध्याय 1–5): टेक्स्ट खोज, अध्याय फ़िल्टर, महत्व फ़िल्टर (अवश्य याद रखें / महत्वपूर्ण / अतिरिक्त), कार्ड व्यू, समयरेखा (timeline) व्यू और हर तिथि का विस्तृत व्यू ("क्या हुआ?", "परीक्षा में महत्व")।
- **क्विज़ इंजन** — एक ही रीयूज़ेबल इंजन, दो मोड: तारीख → घटना और घटना → तारीख। 5 प्रश्न, 4 विकल्प, तुरंत फ़ीडबैक, प्रगति संकेतक, अंतिम स्कोर, फिर से करें, मोड बदलें।
- **रिवीज़न (Quick Revision)** — फ़्लैशकार्ड सत्र ("अवश्य याद रखें" या "अवश्य + महत्वपूर्ण"), शफ़ल, कीबोर्ड सपोर्ट।
- **प्रगति** — समीक्षित तिथियाँ, क्विज़ स्कोर (औसत/सर्वोत्तम), अध्याय-वार प्रगति, हाल के प्रयास; सब कुछ डिवाइस में लोकली सेव।
- **लाइट/डार्क थीम** — सिस्टम प्रेफ़रेंस का सम्मान, चुनाव localStorage में सेव, थीम फ़्लैश (FOUC) से बचाव।
- **पूरी तरह रिस्पॉन्सिव** — मोबाइल बॉटम नेविगेशन, टैबलेट/डेस्कटॉप लेआउट, सुविधाजनक टच टारगेट, हिंदी के लिए बड़ी लाइन-हाइट।

## तकनीक (Technology)

- HTML5 + CSS3 + वेनिला JavaScript — **कोई डिपेंडेंसी नहीं, कोई npm पैकेज नहीं, कोई बैकएंड नहीं**
- क्लासिक (non-module) मॉड्यूलर स्क्रिप्ट्स + छोटा `NB` नेमस्पेस — इसलिए यह `file://` पर डायरेक्ट खोलने पर भी चलती है और GitHub Pages पर भी
- हैश-आधारित SPA रूटिंग (`#/home`, `#/history`, `#/quiz`, `#/revision`, `#/progress`)
- डेटा और UI पूरी तरह अलग (`js/data/` में केवल कंटेंट)

## लोकली चलाना (Run locally)

**तरीका 1 — सीधे खोलें:** `index.html` पर डबल-क्लिक करें। पूरी साइट बिना किसी सर्वर के चलेगी।

**तरीका 2 — लोकल सर्वर (सुझाया गया):**

```bash
# Node.js के साथ
npx serve .

# या Python के साथ
python -m http.server 8080
```

फिर ब्राउज़र में दिखाया गया URL खोलें (जैसे `http://localhost:8080`)।

## रोडमैप (Roadmap)

- **फ़ेज़ 1 (यह बैच):** फ़ाउंडेशन + इतिहास की महत्वपूर्ण तिथियाँ + क्विज़ + रिवीज़न + प्रगति
- **फ़ेज़ 2:** एडवांस्ड क्विज़ + कमज़ोर तिथियाँ (weak dates) + स्पेस्ड रिवीज़न + बेहतर प्रगति
- **फ़ेज़ 3:** दैनिक नोट्स + दैनिक लक्ष्य + अध्याय सारांश + महत्वपूर्ण प्रश्न
- **फ़ेज़ 4:** भूगोल + नागरिक शास्त्र + अर्थशास्त्र + मानचित्र अभ्यास + उत्तर लेखन + मॉक टेस्ट + 90+ मिशन
- **फ़ेज़ 5:** मेमोरी तकनीकें (memoryMethods फ़ील्ड डेटा में पहले से तैयार है) + अंतिम पॉलिश

## वर्तमान सीमाएँ (Current limitations)

- तिथि डेटासेट **प्रारंभिक सत्यापित सैंपल (41 तिथियाँ)** है — पूरा UBSE/NCERT पाठ्यक्रम अभी शामिल नहीं है। भविष्य के फ़ील्ड (`memoryMethods`, `relatedIds`, `tags`, `difficulty`, `revisionLevel`) के लिए संरचना तैयार है।
- PIN गेट केवल एक सुविधा है, सुरक्षा नहीं: स्टैटिक साइट में सच्चा गुप्त रखना संभव नहीं है। सोर्स में PIN सादे टेक्स्ट में नहीं है (केवल सॉल्टेड डाइजेस्ट), फिर भी तकनीकी रूप से देखने वाला इसे हल कर सकता है। अनलॉक की स्थिति `sessionStorage` में रहती है, इसलिए उसी टैब-सत्र में दोबारा नहीं पूछी जाती।
- प्रगति केवल उसी डिवाइस/ब्राउज़र में रहती है (कोई सिंक/बैकअप नहीं)। साइट डेटा साफ़ करने या प्राइवेट विंडो में प्रगति मिट सकती है।
- भूगोल, नागरिक शास्त्र, अर्थशास्त्र, नक्शे, मॉक टेस्ट आदि अभी उपलब्ध नहीं हैं — होम पर इन्हें साफ़ तौर पर "जल्द" दिखाया गया है, नकली बटन नहीं हैं।

## GitHub Pages पर डिप्लॉय

1. रिपॉज़िटरी GitHub पर पब्लिश करें (यह पूरी तरह स्टैटिक है — कोई बिल्ड स्टेप नहीं)।
2. **Settings → Pages → Source: Deploy from a branch** चुनें।
3. Branch: `main`, फ़ोल्डर: `/ (root)` → Save।
4. कुछ मिनट में साइट `https://<username>.github.io/<repo-name>/` पर चलेगी।

नोट: साइट रूट के `index.html` से चलती है, कोई रिलेटिव पाथ समस्या नहीं है; सब-फ़ोल्डर (प्रोजेक्ट पेज) पर भी यह सीधे काम करती है।
